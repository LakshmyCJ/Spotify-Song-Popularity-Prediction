# Spotify Song Popularity Prediction

## Overview
This project analyzes over 1,500 Spotify tracks released between 1998 and 2020 to identify factors associated with song popularity. Using Python, I performed data cleaning, exploratory data analysis (EDA), feature engineering, predictive modeling, and clustering to uncover patterns in music characteristics and listener preferences.

## Objectives
- Analyze relationships between audio features and song popularity
- Identify key drivers of popular songs
- Build predictive models to classify song popularity
- Discover patterns using clustering techniques
- Evaluate potential business impact through profit-based analysis

## Dataset
- 1,500+ Spotify tracks
- Features include danceability, energy, loudness, acousticness, speechiness, valence, tempo, and popularity scores
- Data spans songs released from 1998–2020

## Methods
- Data Cleaning and Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Classification Modeling
- K-Nearest Neighbors (KNN)
- Clustering Analysis
- Model Evaluation

## Results
- Selected KNN as the best-performing model
- Achieved 83.78% prediction accuracy
- Achieved 99.47% recall for identifying popular songs
- Estimated a projected business gain of $338,000 through profit-based optimization
