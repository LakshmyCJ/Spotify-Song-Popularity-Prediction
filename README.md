This project analyzes 1,500+ Spotify tracks from 1998–2020 and demonstrates data validation, exploratory data analysis, feature engineering, predictive modeling, clustering, quantitative analysis, visualization, and communicating insights from complex datasets. 
The analysis includes preparing the dataset, examining relationships among audio and popularity features, building classification models, evaluating model performance, and identifying patterns that can support recommendation or playlist strategy. The project selected a KNN model with 83.78% accuracy and 99.47% recall for popular songs and applied profit-based optimization to estimate a projected gain of $338K.
